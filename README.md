📌 Overview
This project explores global music streaming and viewing trends across Spotify and YouTube, highlighting artist performance, track popularity, and engagement metrics. Built in Power BI after extensive data cleaning in Python/Pandas, the dashboard provides actionable insights into how audiences interact with music across platforms.

🧹 Data Preparation
Removed duplicates and standardized artist/track names.

Normalized metrics (streams, views, likes, comments) for consistency.

Integrated multiple datasets into a unified schema for analysis.

Ensured reproducibility with a clean workflow for future updates.
